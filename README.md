# Solana Transaction Guardian

Solana Transaction Guardian is a read-only ZeroClaw tool plugin that decodes,
simulates, and evaluates serialized or confirmed Solana transactions before
they are trusted.

The project is under active implementation against `PRD.md`. The current
baseline is Milestone M0 and is not yet release-ready.

Custody tier: read-only (T0). The plugin never signs or submits transactions.
