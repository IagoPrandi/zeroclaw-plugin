# M0 skill assessment

## Decision

**DO NOT CREATE**

## Evidence reviewed

- Competition requirements and evidence capture.
- ZeroClaw tag, commit, WIT, component build, and host compatibility work.
- Solana modular-crate and Token-2022 dependency spikes.
- Ollama and `qwen3.5:9b` local tool-calling validation.
- Rust MSRV correction from 1.91.1 to 1.96.1.
- Windows GNU toolchain use after the shell resolved an incompatible MSYS
  `link.exe` instead of the MSVC linker.

## Rationale

M0 is discovery tied to one pinned ZeroClaw release and this repository's
competition constraints. The existing project skill
`.claude/skills/solana-dev` already provides the reusable Solana and
Token-2022 guidance used here. A new skill would mostly duplicate that material
while the host integration procedure is still being validated. Stable commands
and decisions are recorded in the ADRs and runtime evidence instead.

This decision should be revisited if the same ZeroClaw component setup is used
in another project or if a repeatable signing and packaging workflow emerges.
